# AirAware AI

**AI-Powered Air Quality Prediction System**

## Project Overview
AirAware AI is a machine learning-based web application designed to analyse historical air pollution data and predict future PM2.5 levels for Gomti Nagar, Lucknow.

## Technologies Used
- Python
- Flask
- HTML and CSS
- Pandas and NumPy
- Scikit-learn
- Random Forest Regression
- Joblib
- OpenAQ API

## Main Features
- Air quality dashboard
- Historical PM2.5 data analysis
- Machine learning-based PM2.5 prediction
- Prediction results displayed on the website

## Dataset
Historical PM2.5 measurements collected from the OpenAQ platform for Gomti Nagar, Lucknow.

## How to Run
1. Activate the virtual environment.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run the application using `python app.py`.
4. Open `http://127.0.0.1:5000` in your browser.

## Note
Predictions are based on the latest available historical dataset and are not live air-quality readings.
